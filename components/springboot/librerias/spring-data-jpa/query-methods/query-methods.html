Spring Data: Consultas Derivadas por Nombre de Método (Query Methods)

1. ¿Qué son los Query Methods y cómo funcionan?

El mecanismo de Consultas Derivadas (Derived Query Methods) de Spring Data es un analizador sintáctico en tiempo de compilación/arranque que descompone el nombre del método declarado en una interfaz de repositorio y genera automáticamente el Árbol de Sintaxis Abstracta (AST) de la consulta, traduciéndolo al lenguaje nativo del almacén de datos: SQL/JPQL en Spring Data JPA o filtros JSON/BSON en Spring Data MongoDB.

Estructura anatómica de un Query Method

El nombre de todo Query Method se divide en dos bloques principales:

  1. Sujeto (Subject): Define la acción a ejecutar y las restricciones de conteo o límite. Ejemplos: find...By, read...By, get...By, count...By, exists...By, delete...By, findTop3...By, findDistinct...By.
  2. Predicado (Predicate): Define los criterios de filtrado basados en las propiedades de la entidad, combinados mediante operadores lógicos (And, Or) y comparadores (Between, LessThan, Containing, etc.).

2. Catálogo Exhaustivo de Palabras Clave (Keywords)

La siguiente tabla recoge todas las palabras clave admitidas por Spring Data Commons, su traducción equivalente en SQL Relacional (JPA) y en BSON Documental (MongoDB), junto con sus escenarios de uso:

Palabra Clave Ejemplo de Firma de Método Equivalente SQL (JPA) Equivalente BSON (MongoDB) Cuándo Usar / Cuándo NO Usar
And findBySpeciesAndAge(String s, int a) WHERE species = ? AND age = ? { "species": s, "age": a } Usar para intersección de 2-3 filtros. No abusar si se superan 4 filtros simultáneos (usar @Query).
Or findBySpeciesOrVaccinated(String s, boolean v) WHERE species = ? OR vaccinated = ? { "$or": [ { "species": s }, { "vaccinated": v } ] } Usar para unión lógica. No usar en tablas gigantes relacionales sin índices compuestos en ambas columnas.
Is / Equals findByName(String name) o findByNameIs(...) WHERE name = ? { "name": name } Comparación de igualdad estricta. Es el comportamiento por defecto si se omite el comparador.
Between findByAgeBetween(int min, int max) WHERE age BETWEEN ? AND ? { "age": { "$gte": min, "$lte": max } } Rangos continuos cerrados (fechas, edades, precios). No usar para rangos con extremos abiertos.
LessThan / LessThanEqual findByAgeLessThanEqual(int max) WHERE age <= ? { "age": { "$lte": max } } Límites superiores. Ideal para filtros "hasta X años" o "anteriores a cierta fecha".
GreaterThan / GreaterThanEqual findByAgeGreaterThanEqual(int min) WHERE age >= ? { "age": { "$gte": min } } Límites inferiores (umbral mínimo de edad, precios desde X).
After / Before findByAdmissionDateAfter(LocalDate d) WHERE admission_date > ? { "admissionDate": { "$gt": d } } Filtros temporales sobre fechas o marcas de tiempo (LocalDate, Instant).
IsNull / IsNotNull / NotNull findByNameIsNull() / findBySpeciesIsNotNull() WHERE name IS NULL / IS NOT NULL { "name": null } / { "species": { "$ne": null } } Búsqueda de registros incompletos o validados. No requiere pasar parámetro en el método.
Like / NotLike findByNameLike(String pattern) WHERE name LIKE ? { "name": { "$regex": pattern } } Búsquedas con comodín manual explícito (requiere pasar %valor% en el argumento).
StartingWith findByNameStartingWith(String prefix) WHERE name LIKE ? || '%' { "name": { "$regex": "^prefix" } } Autocompletado y búsqueda por prefijo. Aprovecha índices B-Tree en SQL e índices de texto en Mongo.
EndingWith findByNameEndingWith(String suffix) WHERE name LIKE '%' || ? { "name": { "$regex": "suffix$" } } Búsqueda por sufijo (ej. extensiones o dominios de correo). No aprovecha índices B-Tree estándar.
Containing findByNameContaining(String infix) WHERE name LIKE '%' || ? || '%' { "name": { "$regex": "infix" } } Búsqueda general de subcadena. No usar en colecciones enormes sin índices de texto completo (Full-Text Search).
IgnoreCase / AllIgnoreCase findByNameIgnoreCase(String name) WHERE UPPER(name) = UPPER(?) { "name": { "$regex": "^name$", "$options": "i" } } Búsqueda insensible a mayúsculas/minúsculas. En JPA puede invalidar índices si no hay índice funcional.
True / False findByVaccinatedTrue() / findByVaccinatedFalse() WHERE vaccinated = TRUE { "vaccinated": true } Estados booleanos claros. No requiere pasar parámetro booleano en la firma del método.
In / NotIn findBySpeciesIn(Collection<String> s) WHERE species IN (?, ?, ...) { "species": { "$in": [ ... ] } } Filtros multiselección (ej. checkbox de especies). Cuidado con pasar colecciones de más de 1000 elementos en Oracle.
OrderBy...Asc / Desc findBySpeciesOrderByAgeAsc(String s) ORDER BY age ASC .sort({ "age": 1 }) Ordenación estática. Para ordenación dinámica desde la petición web, preferir pasar el parámetro Sort.
Top / First findTop3BySpeciesOrderByAgeDesc(String s) LIMIT 3 .limit(3) Limitar el número de resultados directamente desde el nombre del método sin pasar un Pageable.
Distinct findDistinctBySpecies(String s) SELECT DISTINCT ... db.collection.distinct(...) Eliminar duplicados en el conjunto de resultados.
countBy... countBySpecies(String species) SELECT COUNT(*) ... db.collection.countDocuments(...) Devuelve un long con el número de coincidencias sin cargar las entidades en memoria.
existsBy... existsByName(String name) SELECT 1 ... LIMIT 1 db.collection.find(...).limit(1).size() > 0 Devuelve boolean indicando si existe al menos un registro. Altamente eficiente.
deleteBy... / removeBy... deleteBySpecies(String species) DELETE FROM ... db.collection.deleteMany(...) Elimina registros concurrentes. En JPA requiere @Transactional en la capa de servicio.

3. Ejemplos Prácticos Completos y Simétricos

A continuación se presentan las interfaces de repositorio declarando exactamente los mismos métodos de consulta para nuestro dominio Pet, mostrando la total correspondencia entre Spring Data JPA y Spring Data MongoDB.

3.1. Repositorio Relacional: PostgreSQL / Oracle (Spring Data JPA)


package com.example.petshop.repository.relational;

import com.example.petshop.model.relational.PetEntity;
import org.springframework.data.jpa.repository.JpaRepository;
import org.springframework.stereotype.Repository;

import java.time.LocalDate;
import java.util.Collection;
import java.util.List;
import java.util.Optional;

@Repository
public interface PetJpaRepository extends JpaRepository<PetEntity, Long> {

    // 1. Igualdad directa
    List<PetEntity> findByName(String name);

    // 2. Operador AND
    List<PetEntity> findBySpeciesAndAge(String species, int age);

    // 3. Operador OR
    List<PetEntity> findBySpeciesOrVaccinated(String species, boolean vaccinated);

    // 4. Rango BETWEEN
    List<PetEntity> findByAgeBetween(int minAge, int maxAge);

    // 5. Comparadores numéricos
    List<PetEntity> findByAgeLessThanEqual(int maxAge);
    List<PetEntity> findByAgeGreaterThanEqual(int minAge);

    // 6. Fechas: Before y After
    List<PetEntity> findByAdmissionDateBefore(LocalDate cutoffDate);
    List<PetEntity> findByAdmissionDateAfter(LocalDate startDate);

    // 7. Búsquedas de texto: prefijos, subcadenas e insensibilidad a mayúsculas
    List<PetEntity> findByNameStartingWithIgnoreCase(String prefix);
    List<PetEntity> findByNameContainingIgnoreCase(String infix);

    // 8. Colecciones: Operador IN
    List<PetEntity> findBySpeciesIn(Collection<String> speciesList);

    // 9. Booleanos literales
    List<PetEntity> findByVaccinatedTrue();
    List<PetEntity> findByVaccinatedFalse();

    // 10. Ordenación estática
    List<PetEntity> findBySpeciesOrderByAgeAsc(String species);
    List<PetEntity> findBySpeciesOrderByAdmissionDateDesc(String species);

    // 11. Limitadores de volumen
    List<PetEntity> findTop3BySpeciesOrderByAgeDesc(String species);
    Optional<PetEntity> findFirstBySpeciesOrderByAdmissionDateAsc(String species);

    // 12. Valores nulos
    List<PetEntity> findByNameIsNull();

    // 13. Conteo y verificación de existencia
    long countBySpecies(String species);
    boolean existsByName(String name);

    // 14. Eliminación derivada
    long deleteBySpecies(String species);
}

3.2. Repositorio Documental: MongoDB (Spring Data MongoDB)


package com.example.petshop.repository.nosql;

import com.example.petshop.model.nosql.PetDocument;
import org.springframework.data.mongodb.repository.MongoRepository;
import org.springframework.stereotype.Repository;

import java.time.LocalDate;
import java.util.Collection;
import java.util.List;
import java.util.Optional;

@Repository
public interface PetMongoRepository extends MongoRepository<PetDocument, String> {

    // 1. Igualdad directa (BSON: { "name": name })
    List<PetDocument> findByName(String name);

    // 2. Operador AND (BSON: { "species": species, "age": age })
    List<PetDocument> findBySpeciesAndAge(String species, int age);

    // 3. Operador OR (BSON: { "$or": [ { "species": species }, { "vaccinated": vaccinated } ] })
    List<PetDocument> findBySpeciesOrVaccinated(String species, boolean vaccinated);

    // 4. Rango BETWEEN (BSON: { "age": { "$gte": minAge, "$lte": maxAge } })
    List<PetDocument> findByAgeBetween(int minAge, int maxAge);

    // 5. Comparadores numéricos
    List<PetDocument> findByAgeLessThanEqual(int maxAge);
    List<PetDocument> findByAgeGreaterThanEqual(int minAge);

    // 6. Fechas: Before y After
    List<PetDocument> findByAdmissionDateBefore(LocalDate cutoffDate);
    List<PetDocument> findByAdmissionDateAfter(LocalDate startDate);

    // 7. Búsquedas de texto: prefijos y subcadenas con regex
    List<PetDocument> findByNameStartingWithIgnoreCase(String prefix);
    List<PetDocument> findByNameContainingIgnoreCase(String infix);

    // 8. Colecciones: Operador IN (BSON: { "species": { "$in": [ ... ] } })
    List<PetDocument> findBySpeciesIn(Collection<String> speciesList);

    // 9. Booleanos literales (BSON: { "vaccinated": true })
    List<PetDocument> findByVaccinatedTrue();
    List<PetDocument> findByVaccinatedFalse();

    // 10. Ordenación estática
    List<PetDocument> findBySpeciesOrderByAgeAsc(String species);
    List<PetDocument> findBySpeciesOrderByAdmissionDateDesc(String species);

    // 11. Limitadores de volumen
    List<PetDocument> findTop3BySpeciesOrderByAgeDesc(String species);
    Optional<PetDocument> findFirstBySpeciesOrderByAdmissionDateAsc(String species);

    // 12. Valores nulos
    List<PetDocument> findByNameIsNull();

    // 13. Conteo y verificación de existencia
    long countBySpecies(String species);
    boolean existsByName(String name);

    // 14. Eliminación derivada
    long deleteBySpecies(String species);
}

4. Cuándo Usar y Cuándo NO Usar Derived Query Methods

Escenario Recomendación Motivo Técnico
Consultas de 1 a 3 atributos con condiciones estándar (igualdad, rango, prefijo). USAR Query Methods Ahorra escribir SQL/BSON, se valida en tiempo de compilación y es altamente legible.
Consultas que combinan más de 4 condiciones con And y Or. NO USAR (Pasar a @Query) El nombre del método se vuelve kilométrico, ilegible y muy frágil ante cambios o refactorizaciones.
Consultas que requieren joins relacionales complejos con funciones de agregación (SUM, AVG). NO USAR (Pasar a @Query o Criteria/Specification) Los nombres derivados no soportan expresiones complejas de agregación o subconsultas anidadas.
Comprobar rápidamente si un registro existe por email o DNI. USAR existsBy... Genera un LIMIT 1 optimizado sin cargar la entidad completa en la memoria de la JVM.

5. Contraejemplos y Antipatrones de Query Methods

Contraejemplo 1: El Método "Monstruo"

Concatenar infinitas condiciones en el nombre del método genera código ininteligible y expuesto a errores silenciosos de orden de parámetros. 


// ANTIPATRÓN: Nombre inmanejable y propenso a errores al enlazar parámetros
public interface BadPetRepository extends JpaRepository<PetEntity, Long> {
    List<PetEntity> findBySpeciesAndAgeGreaterThanEqualAndVaccinatedTrueAndAdmissionDateBeforeAndNameContainingIgnoreCaseOrderByAdmissionDateDesc(
        String species, int minAge, LocalDate maxDate, String infix
    );
}

Solución: Extraer la consulta a una anotación @Query limpia o utilizar Specifications/QueryDSL.

Contraejemplo 2: Error de Propiedad Inexistente en Tiempo de Arranque


// ANTIPATRÓN: La propiedad 'birthDate' no existe en PetEntity (es 'admissionDate')
public interface BrokenRepository extends JpaRepository<PetEntity, Long> {
    // Spring lanzará PropertyReferenceException al arrancar la aplicación
    List<PetEntity> findByBirthDate(LocalDate date);
}

Catálogo Integral de Ejemplos de Tests en Spring Boot

1. Guía de Referencia Rápida: La Pirámide de Testing en Spring Boot

En arquitecturas empresariales con Spring Boot, las pruebas se distribuyen en capas según su velocidad de ejecución, grado de aislamiento y fidelidad respecto al entorno de producción:

Capa de Test Anotación Principal Contexto de Spring Velocidad Objetivo Primario
Unitario Puro @ExtendWith(MockitoExtension.class) Ninguno (JVM pura) < 50 ms Lógica de negocio en servicios, validaciones y cálculos.
Slice Web @WebMvcTest(Controlador.class) Solo capa Spring MVC y Jackson 1 - 2 s Rutas HTTP, serialización JSON, códigos de estado y @Valid.
Slice Persistencia @DataJpaTest Solo JPA, Hibernate y DataSource 2 - 4 s Consultas JPQL, derivadas, constraints y mapeos ORM.
Integración E2E @SpringBootTest(webEnvironment = RANDOM_PORT) Completo + Docker Testcontainers 5 - 15 s Flujos reales completos cliente HTTP -> BD real.
---

2. Cuadro Sinóptico de Anotaciones de Testing

Anotación Librería Cuándo Usar Cuándo NO Usar
@Mock Mockito En tests unitarios puros para simular colaboradores sin Spring. En tests de integración o slice tests que requieran inyección de Spring.
@MockBean Spring Boot Test En tests con contexto Spring (@WebMvcTest) para reemplazar un bean real por un mock. En tests unitarios puros (sobrecoste innecesario de contexto).
@InjectMocks Mockito Para instanciar la clase de servicio bajo prueba inyectándole los @Mock. Sobre interfaces o clases administradas por Spring.
@Captor Mockito Para inspeccionar los argumentos reales que recibió un método simulado. Cuando el argumento se puede validar directamente con eq(...).
@DataJpaTest Spring Boot Test Para testear repositorios JPA con rollback automático por defecto. Para probar controladores o servicios de negocio.
@Container Testcontainers Para gestionar el ciclo de vida de un contenedor Docker real (PostgreSQL, Mongo, Kafka). En tests unitarios rápidos donde no interviene la base de datos.
---

3. Ejemplo 1: Test de Repositorio JPA (@DataJpaTest con Heurística Completa)

Verifica el guardado, la recuperación, el caso negativo de restricción @NotNull y la consulta filtrada con su caso contrario: 


package com.example.petshop.repository;

import com.example.petshop.model.relational.PetEntity;
import com.example.petshop.repository.relational.PetJpaRepository;
import org.junit.jupiter.api.DisplayName;
import org.junit.jupiter.api.Test;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.boot.test.autoconfigure.orm.jpa.DataJpaTest;
import org.springframework.boot.test.autoconfigure.orm.jpa.TestEntityManager;
import org.springframework.dao.DataIntegrityViolationException;

import java.time.LocalDate;
import java.util.Optional;

import static org.assertj.core.api.Assertions.assertThat;
import static org.assertj.core.api.Assertions.assertThatThrownBy;

@DataJpaTest
@DisplayName("Slice Test de Persistencia - PetJpaRepository")
class PetJpaRepositoryTest {

    @Autowired
    private PetJpaRepository underTest;

    @Autowired
    private TestEntityManager entityManager;

    @Test
    @DisplayName("Happy Path: Guardar y recuperar mascota por ID en base de datos")
    void shouldSaveAndFindPetById() {
        // GIVEN: Mascota preparada
        PetEntity pet = PetEntity.builder()
                .name("Cooper")
                .species("Dog")
                .age(3)
                .vaccinated(true)
                .admissionDate(LocalDate.now())
                .build();

        // WHEN: Persistir mediante el repositorio
        PetEntity saved = underTest.save(pet);

        // THEN: Recuperar y verificar igualdad profunda
        Optional<PetEntity> found = underTest.findById(saved.getId());
        assertThat(found).isPresent();
        assertThat(found.get())
                .usingRecursiveComparison()
                .ignoringFields("id")
                .isEqualTo(pet);
    }

    @Test
    @DisplayName("Negative Path: Intentar guardar mascota con nombre nulo debe violar constraint @NotNull")
    void shouldThrowDataIntegrityViolationExceptionWhenNameIsNull() {
        // GIVEN: Mascota con campo obligatorio nulo
        PetEntity invalidPet = PetEntity.builder()
                .name(null) // Restricción nullable = false
                .species("Cat")
                .age(2)
                .vaccinated(false)
                .admissionDate(LocalDate.now())
                .build();

        // WHEN & THEN: Falla al sincronizar con la base de datos
        assertThatThrownBy(() -> {
            underTest.save(invalidPet);
            entityManager.flush(); // Fuerza la ejecución inmediata de la sentencia SQL
        }).isInstanceOf(DataIntegrityViolationException.class);
    }

    @Test
    @DisplayName("Filtro y Caso Contrario: findByVaccinatedTrue incluye vacunadas y excluye no vacunadas")
    void shouldFindVaccinatedPetsAndExcludeUnvaccinated() {
        // GIVEN: Se persisten ambos casos en la BD
        PetEntity v1 = PetEntity.builder().name("Milo").species("Dog").age(1).vaccinated(true).admissionDate(LocalDate.now()).build();
        PetEntity v2 = PetEntity.builder().name("Simba").species("Cat").age(4).vaccinated(false).admissionDate(LocalDate.now()).build();
        entityManager.persist(v1);
        entityManager.persist(v2);
        entityManager.flush();

        // WHEN: Búsqueda derivada
        var result = underTest.findByVaccinatedTrue();

        // THEN: Debe contener a Milo y excluir obligatoriamente a Simba
        assertThat(result)
                .extracting(PetEntity::getName)
                .contains("Milo")
                .doesNotContain("Simba");
    }
}

4. Ejemplo 2: Test Unitario de Servicio con ArgumentCaptor (JUnit 5 + Mockito)

Verifica la orquestación lógica, la captura exacta de la entidad que se enviará a persistencia y el manejo de excepciones cuando el registro no existe: 


package com.example.petshop.service;

import com.example.petshop.dto.PetDTO;
import com.example.petshop.exception.PetNotFoundException;
import com.example.petshop.model.relational.PetEntity;
import com.example.petshop.repository.relational.PetJpaRepository;
import org.junit.jupiter.api.DisplayName;
import org.junit.jupiter.api.Test;
import org.junit.jupiter.api.extension.ExtendWith;
import org.mockito.ArgumentCaptor;
import org.mockito.Captor;
import org.mockito.InjectMocks;
import org.mockito.Mock;
import org.mockito.junit.jupiter.MockitoExtension;

import java.time.LocalDate;
import java.util.Optional;

import static org.assertj.core.api.Assertions.assertThat;
import static org.assertj.core.api.Assertions.assertThatThrownBy;
import static org.mockito.ArgumentMatchers.any;
import static org.mockito.BDDMockito.given;
import static org.mockito.BDDMockito.then;
import static org.mockito.Mockito.never;

@ExtendWith(MockitoExtension.class)
@DisplayName("Test Unitario Aislado - PetService")
class PetServiceUnitTest {

    @Mock
    private PetJpaRepository petRepository;

    @InjectMocks
    private PetServiceImpl underTest;

    @Captor
    private ArgumentCaptor<PetEntity> captor;

    @Test
    @DisplayName("Debe capturar la entidad con sus valores convertidos antes de llamar a save()")
    void shouldCaptureEntityAndPersistCorrectly() {
        // GIVEN
        PetDTO dto = PetDTO.builder()
                .name("Bella")
                .species("Rabbit")
                .age((short) 1)
                .vaccinated(true)
                .admissionDate(LocalDate.now())
                .build();

        PetEntity persisted = PetEntity.builder()
                .id(50L)
                .name("Bella")
                .species("Rabbit")
                .age(1)
                .vaccinated(true)
                .admissionDate(LocalDate.now())
                .build();

        given(petRepository.save(captor.capture())).willReturn(persisted);

        // WHEN
        PetDTO result = underTest.registerPet(dto);

        // THEN
        assertThat(result.getId()).isEqualTo(50L);
        PetEntity captured = captor.getValue();
        assertThat(captured.getName()).isEqualTo("Bella");
        assertThat(captured.getSpecies()).isEqualTo("Rabbit");

        then(petRepository).should().save(any(PetEntity.class));
    }

    @Test
    @DisplayName("Debe lanzar excepción y nunca llamar a delete() si el ID no existe")
    void shouldThrowExceptionAndNeverCallDeleteWhenNotFound() {
        // GIVEN
        Long invalidId = 999L;
        given(petRepository.findById(invalidId)).willReturn(Optional.empty());

        // WHEN & THEN
        assertThatThrownBy(() -> underTest.deletePet(invalidId))
                .isInstanceOf(PetNotFoundException.class);

        // Verificamos que NUNCA se intentó borrar nada en la base de datos
        then(petRepository).should(never()).delete(any(PetEntity.class));
    }
}

5. Ejemplo 3: Test Web con MockMvc y Bean Validation (@WebMvcTest)

Prueba el contrato REST, cabeceras HTTP y el rechazo automático de payloads que violen restricciones de validación: 


package com.example.petshop.controller;

import com.example.petshop.dto.PetDTO;
import com.example.petshop.service.PetService;
import com.fasterxml.jackson.databind.ObjectMapper;
import org.junit.jupiter.api.DisplayName;
import org.junit.jupiter.api.Test;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.boot.test.autoconfigure.web.servlet.WebMvcTest;
import org.springframework.boot.test.mock.mockito.MockBean;
import org.springframework.http.MediaType;
import org.springframework.test.web.servlet.MockMvc;

import static org.mockito.ArgumentMatchers.any;
import static org.mockito.BDDMockito.given;
import static org.springframework.test.web.servlet.request.MockMvcRequestBuilders.post;
import static org.springframework.test.web.servlet.result.MockMvcResultMatchers.*;

@WebMvcTest(PetController.class)
@DisplayName("Slice Test Web - PetController Contract & Validation")
class PetControllerSliceTest {

    @Autowired
    private MockMvc mockMvc;

    @Autowired
    private ObjectMapper objectMapper;

    @MockBean
    private PetService petService;

    @Test
    @DisplayName("POST /petshop/pet: Retorna 201 Created cuando el payload es válido")
    void shouldReturn201WhenPayloadIsValid() throws Exception {
        PetDTO valid = PetDTO.builder().name("Thor").species("Dog").age((short) 2).vaccinated(true).build();
        PetDTO saved = PetDTO.builder().id(7).name("Thor").species("Dog").age((short) 2).vaccinated(true).build();

        given(petService.save(any(PetDTO.class))).willReturn(saved);

        mockMvc.perform(post("/petshop/pet")
                .contentType(MediaType.APPLICATION_JSON)
                .content(objectMapper.writeValueAsString(valid)))
                .andExpect(status().isCreated())
                .andExpect(header().exists("Location"));
    }

    @Test
    @DisplayName("POST /petshop/pet: Retorna 400 Bad Request cuando el nombre está en blanco")
    void shouldReturn400WhenNameIsBlank() throws Exception {
        PetDTO invalid = PetDTO.builder().name("").species("Dog").age((short) 2).build();

        mockMvc.perform(post("/petshop/pet")
                .contentType(MediaType.APPLICATION_JSON)
                .content(objectMapper.writeValueAsString(invalid)))
                .andExpect(status().isBadRequest())
                .andExpect(jsonPath("$.status").value(400));
    }
}

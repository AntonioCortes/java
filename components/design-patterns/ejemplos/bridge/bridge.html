Patrón Bridge

El patrón Bridge (Puente) es un patrón estructural que divide una clase grande o un conjunto de clases estrechamente ligadas en dos jerarquías separadas —Abstracción e Implementación— conectadas mediante una referencia, para que ambas puedan evolucionar de forma independiente.

Analogía del Mundo Real

Piensa en los mandos a distancia (Abstracción) y los aparatos electrónicos como un Televisor o una Radio (Implementación). Un mismo mando básico o un mando avanzado con botón de silencio (mute) puede controlar tanto una TV como una Radio porque ambos dispositivos comparten una interfaz de comunicación por infrarrojos (Dispositivo). No necesitas fabricar una clase MandoAvanzadoParaRadioSony y otra MandoBasicoParaTvLG.

Propósito

Evitar la explosión combinatoria de subclases cuando un sistema puede crecer en dos dimensiones ortogonales (por ejemplo: tipos de Mandos × tipos de Dispositivos, o tipos de Formas × motores de Renderizado).

Caso de Uso Real: Mandos a Distancia Universales y Dispositivos

Contexto: Tienes 2 tipos de mandos (MandoDistancia básico y MandoAvanzado) y 2 tipos de dispositivos (Televisor y Radio).

El Problema (Sin Bridge): Si usas herencia tradicional para combinarlos, necesitas 2 × 2 = 4 clases (BasicTvRemote, AdvancedTvRemote, BasicRadioRemote, AdvancedRadioRemote). Si mañana tienes 5 tipos de mandos y 5 dispositivos, ¡tendrás que escribir 25 clases!

La Solución (Con Bridge): Separas los Mandos en una jerarquía y los Dispositivos en otra. La clase base MandoDistancia contiene un atributo protected Dispositivo device (ese atributo es literalmente el Puente). Así, 5 mandos + 5 dispositivos son solo 10 clases en lugar de 25.

Implementación en Java


// 1. Implementor: Interfaz común para todos los dispositivos físicos
interface Dispositivo {
    boolean estaEncendido();
    void encender();
    void apagar();
    int getVolumen();
    void setVolumen(int percent);
}

// 2. Implementadores Concretos: TV y Radio
class Televisor implements Dispositivo {
    private boolean on = false;
    private int volumen = 30;

    @Override
    public boolean estaEncendido() { return on; }
    @Override
    public void encender() { on = true; System.out.println("[TV] Televisor encendido."); }
    @Override
    public void apagar() { on = false; System.out.println("[TV] Televisor apagado."); }
    @Override
    public int getVolumen() { return volumen; }
    @Override
    public void setVolumen(int percent) {
        this.volumen = percent;
        System.out.println("[TV] Volumen ajustado a " + this.volumen + "%");
    }
}

class Radio implements Dispositivo {
    private boolean on = false;
    private int volumen = 20;

    @Override
    public boolean estaEncendido() { return on; }
    @Override
    public void encender() { on = true; System.out.println("[Radio] Radio FM encendida."); }
    @Override
    public void apagar() { on = false; System.out.println("[Radio] Radio FM apagada."); }
    @Override
    public int getVolumen() { return volumen; }
    @Override
    public void setVolumen(int percent) {
        this.volumen = percent;
        System.out.println("[Radio] Volumen ajustado a " + this.volumen + "%");
    }
}

// 3. Abstracción: El Mando base que contiene el PUENTE (referencia a Device)
class MandoDistancia {
    protected Dispositivo dispositivo;

    public MandoDistancia(Dispositivo dispositivo) {
        this.dispositivo = dispositivo;
    }

    public void alternarEncendido() {
        if (dispositivo.estaEncendido()) {
            dispositivo.apagar();
        } else {
            dispositivo.encender();
        }
    }

    public void volumenUp() {
        dispositivo.setVolumen(dispositivo.getVolumen() + 10);
    }
}

// 4. Abstracción Refinada: Mando avanzado con funciones adicionales
class MandoAvanzado extends MandoDistancia {
    public MandoAvanzado(Dispositivo dispositivo) {
        super(dispositivo);
    }

    public void silenciar() {
        System.out.println(">> Pulsado botón MUTE en el mando avanzado");
        dispositivo.setVolumen(0);
    }
}

Análisis Paso a Paso para Principiantes

  • 1. ¿Dónde está el "Puente"?

    El puente es la línea protected Dispositivo dispositivo; dentro de MandoDistancia. En lugar de que el mando herede de Televisor o Radio, se conecta a ellos mediante esa referencia.

  • 2. Diferencia clave entre Adapter y Bridge:

    Adapter se usa a posteriori para hacer que dos clases incompatibles ya existentes funcionen juntas. Bridge se diseña desde el principio para evitar que una jerarquía de clases se multiplique descontroladamente.

Ejemplo de Uso


public class Main {
    public static void main(String[] args) {
        System.out.println("--- Controlando una TV con un Mando Básico ---");
        Dispositivo myTv = new Televisor();
        MandoDistancia basicRemote = new MandoDistancia(myTv);
        basicRemote.alternarEncendido();
        basicRemote.volumenUp();

        System.out.println("\n--- Controlando una Radio con un Mando Avanzado ---");
        Dispositivo myRadio = new Radio();
        MandoAvanzado advancedRemote = new MandoAvanzado(myRadio);
        advancedRemote.alternarEncendido();
        advancedRemote.silenciar();
    }
}
Cualquier mando puede combinarse con cualquier dispositivo

¿Cuándo usarlo y cuándo NO usarlo?

  • Cuándo usarlo: Cuando tengas una clase con varias variantes de funcionalidad y varias variantes de plataforma/dispositivo y quieras combinarlas y extenderlas de forma independiente.
  • Cuándo evitarlo: En clases simples que solo varían en una única dimensión.

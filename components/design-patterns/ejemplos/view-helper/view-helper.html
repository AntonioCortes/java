Patrón View Helper

El patrón View Helper (Ayudante de Vista) es un patrón de la capa de presentación de Java EE que separa el diseño visual de una plantilla (HTML/JSP/Thymeleaf) de la lógica de formateo y adaptación de datos para la pantalla.

Analogía del Mundo Real

Piensa en un presentador de telediario (la Vista) y su equipo de redacción y grafismo (el View Helper). El presentador frente a la cámara no se pone a calcular porcentajes con una calculadora ni a traducir nombres extranjeros en directo: el equipo de redacción le entrega en el teleprónter el texto ya formateado, limpio y listo para leer.

Propósito

Mantener las plantillas de interfaz (vistas) limpias de código Java complejo, delegando en clases auxiliares (Helper) tareas como dar formato a monedas, fechas, nombres completos o etiquetas visuales.

Caso de Uso Real: Formateo de Datos de Cliente y Divisas en una Ficha Web

Contexto: Tienes un objeto de dominio Usuario con nombre ("ana"), apellido ("garcía"), saldo (1250.5) y un booleano vip = true. En la web debe mostrarse como "GARCÍA, Ana [⭐ CLIENTE VIP]" y "1.250,50 €".

El Problema (Sin View Helper): Si metes bloques de código Java dentro del archivo HTML/JSP para capitalizar cadenas, redondear decimales y evaluar condicionales, la plantilla se vuelve ilegible tanto para diseñadores web como para programadores.

La Solución (Con View Helper): Creamos la clase AyudanteVistaUsuario con métodos específicos de presentación (formatearNombre(user), formatBalance(user)). La vista solo invoca al Helper e imprime el resultado directamente.

Implementación en Java


import java.util.Locale;

// 1. Modelo de datos puro (sin lógica de presentación HTML)
class Usuario {
    private String firstName;
    private String lastName;
    private double balance;
    private boolean vip;

    public User(String firstName, String lastName, double balance, boolean vip) {
        this.firstName = firstName;
        this.lastName = lastName;
        this.balance = balance;
        this.vip = vip;
    }

    public String getFirstName() { return firstName; }
    public String getLastName() { return lastName; }
    public double getBalance() { return balance; }
    public boolean isVip() { return vip; }
}

// 2. View Helper: encapsula toda la lógica de formateo para la interfaz
class AyudanteVistaUsuario {

    public String formatearNombre(Usuario user) {
        return user.getLastName().toUpperCase() + ", " + user.getFirstName();
    }

    public String getVipBadge(Usuario user) {
        return user.isVip() ? "[⭐ CLIENTE VIP]" : "[Cliente Estándar]";
    }

    public String getFormattedBalance(Usuario user) {
        return String.format(Locale.US, "%.2f EUR", user.getBalance());
    }
}

// 3. Vista (Simulación de plantilla HTML/Thymeleaf limpia)
class UsuarioProfileView {
    private AyudanteVistaUsuario helper = new AyudanteVistaUsuario();

    public void renderHtml(Usuario user) {
        System.out.println("<div class=\"card-perfil\">");
        System.out.println("  <h2>" + helper.formatearNombre(user) + " " + helper.getVipBadge(user) + "</h2>");
        System.out.println("  <p>Saldo disponible: <strong>" + helper.getFormattedBalance(user) + "</strong></p>");
        System.out.println("</div>");
    }
}

Análisis Paso a Paso para Principiantes

  • 1. Reutilización en todas las pantallas:

    Si muestras el nombre del usuario y su insignia VIP en 10 pantallas distintas (cabecera, perfil, facturas, comentarios), todas llaman al mismo AyudanteVistaUsuario. Si mañana cambias el formato de la insignia, solo editas una línea en el Helper.

  • 2. Fácil de probar con tests unitarios:

    Probar un archivo JSP o HTML es difícil, pero probar que helper.formatearNombre(user) devuelve "GARCÍA, Ana" con un test de JUnit tarda un milisegundo.

Ejemplo de Uso


public class Main {
    public static void main(String[] args) {
        Usuario cliente1 = new Usuario("Ana", "García", 1450.5, true);
        Usuario cliente2 = new Usuario("Pedro", "López", 85.0, false);

        UserProfileView view = new UserProfileView();

        System.out.println("--- Renderizando ficha de Cliente 1 ---");
        view.renderHtml(cliente1);

        System.out.println("\n--- Renderizando ficha de Cliente 2 ---");
        view.renderHtml(cliente2);
    }
}

¿Cuándo usarlo y cuándo NO usarlo?

  • Cuándo usarlo: Siempre que necesites formatear fechas, monedas, textos o etiquetas condicionales para la vista (en Thymeleaf, por ejemplo, los objetos utilitarios como #temporals o #numbers son View Helpers integrados).
  • Cuándo evitarlo: Nunca pongas llamadas a base de datos ni modificaciones de negocio dentro de un View Helper; su única misión es dar formato visual a datos que ya han sido recuperados.

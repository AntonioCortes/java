Patrón Value List Handler

El patrón Value List Handler (Manejador de Lista de Valores) es un patrón de la arquitectura Java EE diseñado para gestionar eficientemente consultas que devuelven listas muy grandes de resultados, ofreciendo al cliente mecanismos de paginación (avanzar y retroceder por bloques o chunks) sin saturar la red ni el navegador.

Analogía del Mundo Real

Piensa en los resultados de búsqueda de Google. Cuando buscas la palabra "Java", Google encuentra 500 millones de páginas web, pero no descarga los 500 millones de resultados de golpe en tu navegador (porque colapsaría tu ordenador). En su lugar, el servidor te entrega solo los primeros 10 resultados (Página 1) y mantiene un puntero para entregarte los siguientes 10 cuando pulses el botón "Siguiente".

Propósito

Evitar enviar miles de objetos por la red en una sola respuesta, permitiendo al cliente pedir únicamente el subconjunto o página de datos (chunk) que cabe actualmente en su pantalla.

Caso de Uso Real: Paginación de un Catálogo de Productos

Contexto: Un usuario busca productos en una tienda y hay una lista grande de resultados, pero en la pantalla del móvil solo caben 3 productos por página.

El Problema (Sin Value List Handler): Si el servidor envía toda la lista completa al cliente cada vez, el consumo de ancho de banda y memoria se dispara innecesariamente.

La Solución (Con Value List Handler): La clase ManejadorListaProductos mantiene la referencia a la búsqueda y un cursor (indiceActual). El cliente pide bloques pequeños llamando a obtenerSiguientePagina(3) para avanzar de página o obtenerPaginaAnterior(3) para retroceder.

Implementación en Java


import java.util.Arrays;
import java.util.Collections;
import java.util.List;

// 1. DAO que recupera los resultados de la búsqueda
class ProductoDAO {
    public List<String> executeSearch() {
        return Arrays.asList(
                "1. Portátil Pro 15\"", "2. Ratón Óptico", "3. Teclado Mecánico",
                "4. Monitor 4K 27\"",   "5. Webcam FullHD", "6. Micrófono USB",
                "7. Silla Ergonómica",  "8. Disco SSD 2TB"
        );
    }
}

// 2. Value List Handler: Gestiona la paginación por bloques (Chunks)
class ManejadorListaProductos {
    private List<String> fullList;
    private int indiceActual = 0;

    public ManejadorListaProductos(ProductoDAO dao) {
        this.fullList = dao.executeSearch();
    }

    // Devuelve los siguientes N elementos y avanza el cursor
    public List<String> obtenerSiguientePagina(int pageSize) {
        if (indiceActual >= fullList.size()) {
            return Collections.emptyList();
        }
        int endIndex = Math.min(indiceActual + pageSize, fullList.size());
        List<String> chunk = fullList.subList(indiceActual, endIndex);
        indiceActual = endIndex;
        return chunk;
    }

    // Retrocede a la página anterior
    public List<String> obtenerPaginaAnterior(int pageSize) {
        indiceActual = Math.max(0, indiceActual - (pageSize * 2));
        return obtenerSiguientePagina(pageSize);
    }
}

Análisis Paso a Paso para Principiantes

  • 1. Su evolución moderna en Spring Data JPA (Page<T> y Pageable):

    En aplicaciones modernas con Spring Boot, cuando usas PageRequest.of(pageNumber, pageSize) y tu repositorio devuelve un objeto Page<Product>, estás utilizando la evolución moderna del patrón Value List Handler apoyada directamente en LIMIT y OFFSET de SQL.

  • 2. Control del tamaño de página:

    El uso de Math.min(indiceActual + pageSize, fullList.size()) garantiza que en la última página (cuando quedan 2 productos en lugar de 3) no se produzca un error IndexOutOfBoundsException.

Ejemplo de Uso


public class Main {
    public static void main(String[] args) {
        ManejadorListaProductos listHandler = new ManejadorListaProductos(new ProductoDAO());
        int pageSize = 3; // Mostrar de 3 en 3 productos por pantalla

        System.out.println("📄 [Página 1] Siguientes 3 productos:");
        System.out.println("   " + listHandler.obtenerSiguientePagina(pageSize));

        System.out.println("\n📄 [Página 2] Usuario pulsa 'Siguiente':");
        System.out.println("   " + listHandler.obtenerSiguientePagina(pageSize));

        System.out.println("\n📄 [Página 3] Usuario pulsa 'Siguiente' (últimos 2 elementos):");
        System.out.println("   " + listHandler.obtenerSiguientePagina(pageSize));
    }
}

¿Cuándo usarlo y cuándo NO usarlo?

  • Cuándo usarlo: En cualquier buscador, listado de facturas, historial de movimientos bancarios o catálogo que pueda devolver más de unas pocas decenas de registros.
  • Cuándo evitarlo: En listas desplegables cortas y fijas (como los 7 días de la semana o los meses del año) donde caben todos los elementos sin paginar.

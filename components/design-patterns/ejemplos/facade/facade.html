Patrón Facade

El patrón Facade (Fachada) es un patrón estructural que proporciona una interfaz única y simplificada frente a un subsistema complejo formado por muchas clases, bibliotecas o frameworks.

Analogía del Mundo Real

Piensa en cuando haces un pedido por teléfono o en la web de una tienda: tú hablas únicamente con el Servicio de Atención al Cliente (la Fachada). No tienes que llamar tú mismo por separado al almacén para verificar stock, luego a la pasarela bancaria para cobrar, luego a contabilidad para emitir la factura y finalmente a la empresa de reparto. Atención al Cliente recibe tu única llamada y coordina todos esos departamentos internos por ti.

Propósito

Ocultar la complejidad de un subsistema detrás de una clase de alto nivel fácil de usar, reduciendo el acoplamiento entre el código cliente y las decenas de clases internas del subsistema.

Caso de Uso Real: Sistema de Cine en Casa (Smart Home)

Contexto: Tienes un salón inteligente con múltiples dispositivos independientes: luces regulables (LucesSala), proyector (Proyector), amplificador de sonido (Amplificador) y reproductor de streaming (ReproductorStreaming).

El Problema (Sin Facade): Para ver una película, el cliente tiene que instanciar las 4 clases y recordar llamar a 7 métodos en el orden exacto: atenuar las luces al 10%, encender el proyector, poner modo panorámico, encender el amplificador, ajustar el volumen, encender el reproductor y darle a reproducir. Y al terminar la película, repetir todo a la inversa.

La Solución (Con Facade): Creamos la clase FachadaCineEnCasa con dos métodos sencillos: verPelicula(titulo) y terminarPelicula(). La fachada se encarga de orquestar internamente todos los aparatos en el orden correcto.

Implementación en Java


// 1. Clases del Subsistema Complejo
class LucesSala {
    public void atenuar(int level) {
        System.out.println("[Luces] Atenuando iluminación de la sala al " + level + "%");
    }
    public void encender() {
        System.out.println("[Luces] Encendiendo luces al 100%");
    }
}

class Proyector {
    public void encender() {
        System.out.println("[Proyector] Encendiendo lámpara láser...");
    }
    public void modoPantallaAncha() {
        System.out.println("[Proyector] Configurando formato panorámico 16:9");
    }
    public void apagar() {
        System.out.println("[Proyector] Apagando proyector.");
    }
}

class Amplificador {
    public void encender() {
        System.out.println("[Amplificador] Encendiendo sonido envolvente Dolby Atmos");
    }
    public void setVolumen(int level) {
        System.out.println("[Amplificador] Ajustando volumen al nivel " + level);
    }
    public void apagar() {
        System.out.println("[Amplificador] Apagando amplificador.");
    }
}

class ReproductorStreaming {
    public void encender() {
        System.out.println("[Reproductor] Conectando al servidor de streaming...");
    }
    public void reproducir(String movie) {
        System.out.println("[Reproductor] ▶ Reproduciendo película: \"" + movie + "\"");
    }
    public void stop() {
        System.out.println("[Reproductor] ⏹ Deteniendo reproducción.");
    }
}

// 2. Clase Facade: ofrece una interfaz simple y unificada
class FachadaCineEnCasa {
    private LucesSala lights;
    private Proyector projector;
    private Amplificador amp;
    private ReproductorStreaming player;

    public FachadaCineEnCasa(LucesSala lights, Proyector projector,
                             Amplificador amp, ReproductorStreaming player) {
        this.lights = lights;
        this.projector = projector;
        this.amp = amp;
        this.player = player;
    }

    // Un único método orquesta los 7 pasos necesarios
    public void verPelicula(String movie) {
        System.out.println(">> Preparando el cine en casa para ver una película...");
        lights.atenuar(10);
        projector.encender();
        projector.modoPantallaAncha();
        amp.encender();
        amp.setVolumen(25);
        player.encender();
        player.reproducir(movie);
    }

    public void terminarPelicula() {
        System.out.println(">> Apagando el cine en casa...");
        player.stop();
        amp.apagar();
        projector.apagar();
        lights.encender();
    }
}
Implementación completa del patrón Facade

Análisis Paso a Paso para Principiantes

  • 1. Simplificación sin ocultar capacidades avanzadas:

    FachadaCineEnCasa resuelve el caso de uso habitual del 95% de los usuarios con una sola llamada (verPelicula), pero no bloquea el acceso directo a Amplificador si algún usuario avanzado necesita ajustar el ecualizador manualmente.

  • 2. Diferencia con Adapter:

    Adapter envuelve normalmente un objeto para cambiar su interfaz por otra ya existente. Facade envuelve todo un grupo de objetos para ofrecer una interfaz nueva y mucho más sencilla.

Ejemplo de Uso


public class Main {
    public static void main(String[] args) {
        // Inicializamos los componentes y la fachada
        FachadaCineEnCasa homeTheater = new FachadaCineEnCasa(
                new LucesSala(),
                new Proyector(),
                new Amplificador(),
                new ReproductorStreaming()
        );

        // El cliente solo hace UNA llamada para encender todo el sistema
        homeTheater.verPelicula("Interstellar");

        System.out.println();

        // Y UNA llamada para apagarlo todo ordenadamente
        homeTheater.terminarPelicula();
    }
}

¿Cuándo usarlo y cuándo NO usarlo?

  • Cuándo usarlo: Cuando quieras ofrecer una puerta de entrada sencilla a un subsistema complejo o dividir una aplicación grande en capas que solo se comuniquen a través de fachadas bien definidas.
  • Cuándo evitarlo: Evita que la fachada se convierta en una "Clase Dios" (God Object) que absorba toda la lógica de negocio en vez de limitarse a coordinar a las clases del subsistema.

Patrón Composite View

El patrón Composite View (Vista Compuesta) es un patrón de la capa de presentación de Java EE que permite construir una página completa ensamblando múltiples sub-vistas o fragmentos independientes (cabecera, menú lateral, pie de página y contenido central dinámico).

Analogía del Mundo Real

Piensa en la portada de un periódico o el marco de esta misma aplicación web. La cabecera con el logotipo del periódico, la columna lateral de secciones y el pie de página legal son piezas fijas que se reutilizan todos los días; lo único que se sustituye en el hueco central es la noticia principal del día. En lugar de rediseñar el periódico entero desde cero para cada página, usas una Plantilla Maestra (Layout) con huecos donde encajan los módulos.

Propósito

Evitar copiar y pegar el código HTML de la barra de navegación (Header), barra lateral (Sidebar) y pie de página (Footer) en decenas de pantallas distintas, garantizando una apariencia uniforme y fácil de mantener.

Caso de Uso Real: Plantillas Maestras en Aplicaciones Web (Thymeleaf Layouts / WebComponents)

Contexto: Tu portal tiene 100 páginas distintas, pero todas comparten el mismo SubVistaCabecera, el mismo SubVistaLateral y el mismo SubVistaPiePagina.

El Problema (Sin Composite View): Si duplicas el HTML de la cabecera en las 100 páginas y mañana hay que añadir un nuevo enlace al menú superior, tendrás que editar 100 archivos manualmente.

La Solución (Con Composite View): Creas un motor de plantilla maestra (MotorPlantillaCompuesta) que ensambla automáticamente las sub-vistas fijas (Header, Sidebar, Footer) e inyecta en la zona central únicamente la sub-vista dinámica (SubVistaCuerpoDinamico) que corresponda a cada sección.

Implementación en Java


// 1. Interfaz común para cualquier fragmento de vista (Sub-Vista)
interface SubVista {
    void renderizar();
}

// 2. Sub-Vistas Fijas Reutilizables
class SubVistaCabecera implements SubVista {
    @Override
    public void renderizar() {
        System.out.println("[HEADER]  === 🧭 Barra de Navegación Superior Corporativa ===");
    }
}

class SubVistaLateral implements SubVista {
    @Override
    public void renderizar() {
        System.out.println("[SIDEBAR] |-- Menú Lateral: [Inicio] [Catálogo] [Mi Cuenta]");
    }
}

class SubVistaPiePagina implements SubVista {
    @Override
    public void renderizar() {
        System.out.println("[FOOTER]  === © 2026 Mi Empresa - Todos los derechos reservados ===");
    }
}

// 3. Sub-Vista Dinámica (Cambia según la página solicitada)
class SubVistaCuerpoDinamico implements SubVista {
    private String pageTitle;
    private String bodyContent;

    public SubVistaCuerpoDinamico(String pageTitle, String bodyContent) {
        this.pageTitle = pageTitle;
        this.bodyContent = bodyContent;
    }

    @Override
    public void renderizar() {
        System.out.println("[BODY]    >> SECCIÓN: " + pageTitle + " -> " + bodyContent);
    }
}

// 4. Composite View: Plantilla Maestra que ensambla todas las piezas
class MotorPlantillaCompuesta {
    private SubVista header = new SubVistaCabecera();
    private SubVista sidebar = new SubVistaLateral();
    private SubVista footer = new SubVistaPiePagina();

    public void renderFullPage(SubVista dynamicBody) {
        header.renderizar();
        sidebar.renderizar();
        dynamicBody.renderizar(); // Inyecta el contenido específico en el hueco central
        footer.renderizar();
    }
}

Análisis Paso a Paso para Principiantes

  • 1. ¡Esta misma web donde estás leyendo esto usa Composite View!

    Como explica el README.md de este proyecto, la barra superior (navbar.html) y la barra lateral (sidebar.html) son fragmentos independientes, y solo se recarga el componente central (#content) cuando pulsas un enlace.

  • 2. Aplicación del patrón Composite de GoF a la Interfaz:

    Es la adaptación directa del patrón estructural Composite al mundo de las plantillas web (como Apache Tiles, Thymeleaf Layout Dialect, o los componentes de Angular/React/WebComponents).

Ejemplo de Uso


public class Main {
    public static void main(String[] args) {
        MotorPlantillaCompuesta masterLayout = new MotorPlantillaCompuesta();

        System.out.println("--- Renderizando Página 1: Catálogo de Productos ---");
        SubVista catalogoBody = new SubVistaCuerpoDinamico("Catálogo", "Mostrando 25 ofertas disponibles.");
        masterLayout.renderFullPage(catalogoBody);

        System.out.println("\n--- Renderizando Página 2: Perfil de Usuario ---");
        SubVista perfilBody = new SubVistaCuerpoDinamico("Mi Perfil", "Datos personales de Antonio.");
        masterLayout.renderFullPage(perfilBody);
    }
}

¿Cuándo usarlo y cuándo NO usarlo?

  • Cuándo usarlo: En cualquier aplicación web con múltiples pantallas que compartan cabecera, menú lateral o pie de página.
  • Cuándo evitarlo: En una landing page de una sola pantalla sencilla sin fragmentos reutilizables.

Ejemplos Prácticos con Apache HttpClient

A continuación se muestran los casos de uso más habituales al consumir una API REST externa (como el microservicio PetShop) utilizando Apache HttpClient junto con la librería Jackson (ObjectMapper) para serializar y deserializar objetos PetDTO.

1. Petición GET con Query Params y conversión a DTO con Jackson

En este ejemplo se realiza una llamada HTTP GET al endpoint /petshop/pet/all?age=4 construido con URIBuilder. Si el servidor responde con un código 200 OK, se extrae el JSON del cuerpo de la respuesta con EntityUtils.toString() y se convierte en una lista de objetos PetDTO mediante ObjectMapper:


import com.fasterxml.jackson.core.type.TypeReference;
import com.fasterxml.jackson.databind.ObjectMapper;
import java.net.URI;
import java.nio.charset.StandardCharsets;
import java.util.Collections;
import java.util.List;
import org.apache.http.HttpEntity;
import org.apache.http.HttpHeaders;
import org.apache.http.HttpStatus;
import org.apache.http.client.methods.CloseableHttpResponse;
import org.apache.http.client.methods.HttpGet;
import org.apache.http.client.utils.URIBuilder;
import org.apache.http.impl.client.CloseableHttpClient;
import org.apache.http.impl.client.HttpClients;
import org.apache.http.util.EntityUtils;

public List<PetDTO> findPetsByAge(int age) throws Exception 
{
	URI uri = new URIBuilder("http://localhost:8080/petshop/pet/all")
			.addParameter("age", String.valueOf(age))
			.build();

	HttpGet request = new HttpGet(uri);
	request.setHeader(HttpHeaders.ACCEPT, "application/json");

	try (CloseableHttpClient httpClient = HttpClients.createDefault();
	     CloseableHttpResponse response = httpClient.execute(request)) 
	{
		int statusCode = response.getStatusLine().getStatusCode();
		HttpEntity entity = response.getEntity();

		if (statusCode == HttpStatus.SC_OK && entity != null) 
		{
			String jsonResponse = EntityUtils.toString(entity, StandardCharsets.UTF_8);
			ObjectMapper objectMapper = new ObjectMapper();
			return objectMapper.readValue(jsonResponse, new TypeReference<List<PetDTO>>() {});
		}
		return Collections.emptyList();
	}
}

2. Petición POST enviando un objeto JSON en el Body

Para dar de alta una nueva mascota llamando al endpoint POST /petshop/pet, se convierte la instancia de PetDTO a una cadena JSON con objectMapper.writeValueAsString(), se envuelve en un StringEntity con tipo ContentType.APPLICATION_JSON y se comprueba el código 201 Created junto con la cabecera Location devuelta por el controlador:


import com.fasterxml.jackson.databind.ObjectMapper;
import org.apache.http.Header;
import org.apache.http.HttpHeaders;
import org.apache.http.HttpStatus;
import org.apache.http.client.methods.CloseableHttpResponse;
import org.apache.http.client.methods.HttpPost;
import org.apache.http.entity.ContentType;
import org.apache.http.entity.StringEntity;
import org.apache.http.impl.client.CloseableHttpClient;
import org.apache.http.impl.client.HttpClients;

public String createPet(PetDTO newPet) throws Exception 
{
	ObjectMapper objectMapper = new ObjectMapper();
	String jsonPayload = objectMapper.writeValueAsString(newPet);

	HttpPost postRequest = new HttpPost("http://localhost:8080/petshop/pet");
	postRequest.setEntity(new StringEntity(jsonPayload, ContentType.APPLICATION_JSON));

	try (CloseableHttpClient httpClient = HttpClients.createDefault();
	     CloseableHttpResponse response = httpClient.execute(postRequest)) 
	{
		int statusCode = response.getStatusLine().getStatusCode();
		if (statusCode == HttpStatus.SC_CREATED) 
		{
			Header locationHeader = response.getFirstHeader(HttpHeaders.LOCATION);
			return locationHeader != null ? locationHeader.getValue() : null;
		} 
		else 
		{
			throw new RuntimeException("Error al crear la mascota. Código HTTP: " + statusCode);
		}
	}
}

3. Envío de un Formulario URL-Encoded (UrlEncodedFormEntity)

Cuando el servidor espera los datos como un formulario clásico (por ejemplo en un endpoint de login OAuth2 o un sistema legado), se construye una lista de objetos NameValuePair y se codifica mediante UrlEncodedFormEntity:


import java.nio.charset.StandardCharsets;
import java.util.ArrayList;
import java.util.List;
import org.apache.http.NameValuePair;
import org.apache.http.client.entity.UrlEncodedFormEntity;
import org.apache.http.client.methods.CloseableHttpResponse;
import org.apache.http.client.methods.HttpPost;
import org.apache.http.impl.client.CloseableHttpClient;
import org.apache.http.impl.client.HttpClients;
import org.apache.http.message.BasicNameValuePair;
import org.apache.http.util.EntityUtils;

public String sendLoginForm(String username, String password) throws Exception 
{
	HttpPost post = new HttpPost("http://localhost:8080/login");

	// Definir los campos del formulario
	List<NameValuePair> urlParameters = new ArrayList<>();
	urlParameters.add(new BasicNameValuePair("username", username));
	urlParameters.add(new BasicNameValuePair("password", password));

	post.setEntity(new UrlEncodedFormEntity(urlParameters, StandardCharsets.UTF_8));

	try (CloseableHttpClient httpClient = HttpClients.createDefault();
	     CloseableHttpResponse response = httpClient.execute(post)) 
	{
		return EntityUtils.toString(response.getEntity(), StandardCharsets.UTF_8);
	}
}

4. Peticiones con Autenticación (Bearer Token y Basic Auth)

A. Autenticación mediante Token JWT (Bearer Token)

Se envía el token directamente en la cabecera estándar Authorization con el prefijo "Bearer ":


HttpGet request = new HttpGet("http://localhost:8080/petshop/pet/15");
request.setHeader(HttpHeaders.AUTHORIZATION, "Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...");

B. Autenticación Básica HTTP con CredentialsProvider

Para configurar autenticación básica (usuario y contraseña) a nivel de cliente utilizando BasicCredentialsProvider y UsernamePasswordCredentials (paquete org.apache.http.auth.*):


import org.apache.http.auth.AuthScope;
import org.apache.http.auth.UsernamePasswordCredentials;
import org.apache.http.client.CredentialsProvider;
import org.apache.http.client.methods.CloseableHttpResponse;
import org.apache.http.client.methods.HttpGet;
import org.apache.http.impl.client.BasicCredentialsProvider;
import org.apache.http.impl.client.CloseableHttpClient;
import org.apache.http.impl.client.HttpClients;

CredentialsProvider provider = new BasicCredentialsProvider();
provider.setCredentials(
		AuthScope.ANY,
		new UsernamePasswordCredentials("admin", "secretPassword")
);

try (CloseableHttpClient httpClient = HttpClients.custom()
		.setDefaultCredentialsProvider(provider)
		.build();
     CloseableHttpResponse response = httpClient.execute(new HttpGet("http://localhost:8080/api/pet"))) 
{
	System.out.println("Código de estado con Basic Auth: " + response.getStatusLine().getStatusCode());
}

5. Uso de ResponseHandler (Buenas Prácticas)

La documentación oficial de Apache recomienda utilizar la interfaz funcional ResponseHandler<T> (paquete org.apache.http.client.ResponseHandler) al llamar a httpClient.execute(request, responseHandler). De esta forma, Apache HttpClient se encarga automáticamente de consumir el stream y cerrar la respuesta y la conexión en todos los casos (incluso si salta una excepción al transformar el JSON):


import com.fasterxml.jackson.databind.ObjectMapper;
import java.nio.charset.StandardCharsets;
import org.apache.http.HttpEntity;
import org.apache.http.client.ClientProtocolException;
import org.apache.http.client.ResponseHandler;
import org.apache.http.client.methods.HttpGet;
import org.apache.http.impl.client.CloseableHttpClient;
import org.apache.http.impl.client.HttpClients;
import org.apache.http.util.EntityUtils;

try (CloseableHttpClient httpClient = HttpClients.createDefault()) 
{
	HttpGet httpGet = new HttpGet("http://localhost:8080/petshop/pet/15");

	// Definición del ResponseHandler mediante una expresión lambda
	ResponseHandler<PetDTO> responseHandler = response -> {
		int status = response.getStatusLine().getStatusCode();
		if (status >= 200 && status < 300) 
		{
			HttpEntity entity = response.getEntity();
			if (entity == null) 
			{
				return null;
			}
			String json = EntityUtils.toString(entity, StandardCharsets.UTF_8);
			return new ObjectMapper().readValue(json, PetDTO.class);
		} 
		else 
		{
			throw new ClientProtocolException("Estado de respuesta inesperado: " + status);
		}
	};

	// Ejecución limpia: HttpClient gestiona y libera automáticamente el CloseableHttpResponse
	PetDTO pet = httpClient.execute(httpGet, responseHandler);
}

¿Cuándo usar cada patrón de ejecución y cuándo NO usarlo?

  • try-with-resources con CloseableHttpResponse: Cuando se necesita inspeccionar cabeceras, el código de estado y el cuerpo con control total.
  • ResponseHandler: Cuando solo se quiere el resultado ya convertido y garantizar el cierre automático.
  • Un cliente nuevo por petición: No hacerlo; se crea un único CloseableHttpClient compartido (es thread-safe) para reutilizar el pool de conexiones.
  • Credenciales en el código: No escribir usuarios, contraseñas ni tokens a mano; se leen de configuración o de variables de entorno.

6. Ejemplo y Contraejemplo: Lectura del Cuerpo de la Respuesta (HttpEntity)

Contraejemplo (Mala práctica): Intentar leer dos veces el flujo de response.getEntity()

El contenido de response.getEntity() es un flujo de red de un solo uso (non-repeatable stream). Si llamamos una primera vez a EntityUtils.toString(response.getEntity()) para imprimir la respuesta en el log y luego volvemos a llamar a EntityUtils.toString(response.getEntity()) o response.getEntity().getContent() para parsear el JSON con Jackson, la segunda llamada lanzará una excepción IOException: Attempted read from closed stream porque el flujo ya se consumió y cerró en la primera lectura:


// CONTRAEJEMPLO (INCORRECTO): Consumir dos veces el stream de response.getEntity() lanza IOException
try (CloseableHttpResponse response = httpClient.execute(httpGet)) 
{
	// 1ª lectura: consume y cierra el InputStream subyacente
	log.debug("Respuesta recibida: {}", EntityUtils.toString(response.getEntity()));

	// 2ª lectura: ¡FALLA! Lanza IOException: Attempted read from closed stream
	PetDTO pet = objectMapper.readValue(EntityUtils.toString(response.getEntity()), PetDTO.class);
}

Ejemplo (Buena práctica): Guardar el resultado de EntityUtils.toString() en una variable

El flujo de la entidad debe leerse una única vez almacenando el texto resultante en una variable String en memoria, la cual ya puede reutilizarse tantas veces como sea necesario para logs y deserialización:


// EJEMPLO (CORRECTO): Se lee el stream una sola vez a un String y se reutiliza la variable
try (CloseableHttpResponse response = httpClient.execute(httpGet)) 
{
	String jsonBody = EntityUtils.toString(response.getEntity(), StandardCharsets.UTF_8);

	log.debug("Respuesta recibida: {}", jsonBody);
	PetDTO pet = objectMapper.readValue(jsonBody, PetDTO.class);
}
